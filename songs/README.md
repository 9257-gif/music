# 公开歌曲库

把你希望别人也能听到的歌曲文件放到这个文件夹，然后编辑 `manifest.json`。

示例：

```json
{
  "tracks": [
    {
      "title": "歌曲名",
      "artist": "歌手",
      "album": "我的歌单",
      "mood": "流行",
      "tag": "MP3",
      "duration": 0,
      "src": "./songs/song-name.mp3"
    }
  ]
}
```

注意：

- `src` 必须和真实文件名一致。
- 文件名尽量使用英文、数字、横线，避免空格和特殊符号。
- `duration` 可以填 `0`，浏览器会自动读取。
- Vercel 不适合放特别大的音乐库。少量歌曲可以直接放这里；大量歌曲建议使用云存储。
